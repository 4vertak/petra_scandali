# C2 — s21_string

Учебная реализация части `string.h` на C11 для Школы 21. Библиотека копирует и сравнивает блоки памяти, ищет подстроки и разбивает строки на токены. Дополнительные функции меняют регистр, вставляют подстроку и удаляют заданные символы с обоих концов строки.

С форматом `x=%d` функция `s21_sprintf` запишет число `42` как строку `x=42`, а `s21_sscanf` прочитает из неё целое число.

## Сборка и тесты

Для сборки нужны GCC и GNU Make, для тестов — библиотека Check и `pkg-config`. Обе команды запускаются из каталога `C2`.

```sh
make -C src s21_string.a
make -C src test
```

Команда `make -C src gcov_report` создаёт HTML-отчёт о покрытии в `src/report/gcov_report.html`. Для неё нужен `gcovr`.
