# C4 — s21_math

Учебная реализация 15 функций `math.h` на C11 для Школы 21. Проект собирается в статическую библиотеку `s21_math.a`. Углы задаются в радианах. Из перечисленных ниже функций `s21_abs` работает с `int`, остальные принимают аргументы типа `double` и возвращают `long double`.

| Операция | Функции |
| --- | --- |
| Модуль, округление и остаток | `s21_abs`, `s21_fabs`, `s21_ceil`, `s21_floor`, `s21_fmod` |
| Тригонометрия | `s21_sin`, `s21_cos`, `s21_tan` |
| Обратная тригонометрия | `s21_asin`, `s21_acos`, `s21_atan` |
| Экспонента, логарифм, степень и корень | `s21_exp`, `s21_log`, `s21_pow`, `s21_sqrt` |

Вычисления рассчитаны на `double` формата IEEE 754 binary64 и используют `long double` для промежуточных результатов. Для `INT_MIN` функция `s21_abs` возвращает сам аргумент, поскольку его положительный модуль выходит за диапазон `int`. В заголовке также доступны `s21_factorial` для факториала и `s21_pow_int` для степени с целым показателем.

## Сборка и подключение

Команды выполняются из каталога `C4`. Для сборки нужны GCC, GNU Make и утилита `ar`.

```sh
make -C src
```

Чтобы получить квадратный корень из двух, сохраните пример в `example.c` рядом с каталогом `src`.

```c
#include <stdio.h>

#include "s21_math.h"

int main(void) {
  printf("%.6Lf\n", s21_sqrt(2.0));
  return 0;
}
```

```sh
gcc -std=c11 -Isrc example.c src/s21_math.a -o example
./example
```

Программа выведет `1.414214`.

## Тесты и покрытие

Для тестов нужны Check 0.15 и `pkg-config`. Тесты сверяют значения с системной математической библиотекой, включая результаты для `NaN`, бесконечностей, знакового нуля и крайних значений `double`. Для отчёта нужны `gcov` из комплекта GCC и `gcovr`.

```sh
make -C src test
make -C src gcov_report
```

Откройте `src/report/gcov_report.html`, чтобы увидеть покрытие по файлам и строкам. Сводка по каждой функции записывается в `src/report/functions.txt`. Цель `gcov_report` возвращает ошибку, если тест упал или покрытие строк хотя бы одной функции ниже 80 %.

Команда `make -C src leaks` запускает те же проверки с санитайзерами GCC для поиска утечек, ошибок доступа к памяти и неопределённого поведения. Команда `make -C src style` проверяет оформление через `clang-format`, а `make -C src clean` удаляет результаты сборки и отчёт.
